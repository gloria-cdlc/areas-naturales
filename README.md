# Análise de Uso do Solo e Cobertura Vegetal no Rio de Janeiro

### O que faz o projeto?

Este projeto foi desenvolvido apenas como exemplo prático para a
disciplina de **Reprodutibilidade de Dados**.

O objetivo é demonstrar a organização de um projeto em R utilizando Git
e GitHub, seguindo boas práticas de reprodutibilidade, incluindo a
estruturação de pastas, importação de dados, transformação das
informações e geração de resultados.

Como exemplo, a análise realiza:

- Importação de bases de dados em formato Excel
- Organização das categorias de uso do solo
- Cálculo das áreas de vegetação natural, antropismos e corpos d’água
  continentais
- Cálculo das porcentagens de cada categoria em relação ao uso total do
  solo
- Geração de um gráfico com a porcentagem de antropismos por região

### Estrutura das pastas

- **DATA/**  
  Contém os arquivos de entrada (.xlsx) utilizados na análise

- **SCRIPT/**  
  Contém o script em R responsável pela importação, manipulação e
  análise dos dados

- **OUTPUT/**  
  Contém os arquivos gerados durante a execução do script, como gráficos
  e demais resultados
